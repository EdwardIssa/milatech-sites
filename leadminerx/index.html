02 / What it does

A full city pull, not the first 60 results

01Single search

Type a keyword and a location (“Real estate agents | Troy, MI”) and get a CSV of every matching business: name, category, rating, review count, address, phone, website.

02Bulk mode

Paste a list, one keyword | location per line, and mine a whole territory in one run.

03Grid deep sweep

A single Google search stops at about 60 results. Deep sweep divides the map into a grid and searches each cell, so a full city pull returns hundreds of leads instead of the first 60.

04Persistent dedup database

Every mined lead is remembered. Run the same search next month and duplicates are skipped automatically — you never pay for the same lead twice.

05Streaming CSV

Rows are written to the file as they arrive, not at the end. Stop a run at any point and everything mined so far is already saved.

06Your data stays yours

The app runs entirely on your machine. Your API key, your searches, and your CSVs never pass through us.

04 / Your API key

Bring your own key — that’s the whole point

This is a bring-your-own-key tool. That’s deliberate — it’s why there’s no per-result fee.

  1. Create a free Google Cloud accountStep 1

    Use the account you have, or make one, and enable the Places API (New). Google asks for a billing card on the account; that’s Google’s requirement for API access, and it applies even if your usage stays inside the free allotment and your bill is $0.

  2. Follow the in-app setup wizardStep 2

    The wizard walks you through the key step by step and tests it before you mine anything. Most people are running in a few minutes.

  3. Your key stays on your machineStep 3

    It’s entered into the app, stored locally, and used only to call Google from your computer. We never see it, and we never see your leads. The key is yours, the billing account is yours, and you can set budgets and alerts in Google Cloud like any other API.

  4. What it costs youThe rate

    Because LeadMiner requests phone, website, rating, and review count, Google bills its requests at the Text Search Enterprise rate — 1,000 requests free per month, then $35 per 1,000 requests. Each request returns up to 20 leads, so your first ~1,000 requests each month cost $0 (up to ~20,000 leads), and every 1,000 leads after that cost about $1.75 — paid to Google, not us. LeadMiner adds nothing on top.

What the API does not provide: email addresses. Google doesn’t return them, and this tool doesn’t pretend to. You get the business’s phone and website — the contact points the business itself publishes.

06 / FAQ

Straight answers

Does it work on Mac?

Not natively — v3 is Windows-only. Mac users run it inside a Windows virtual machine (Parallels, VMware, UTM) and it works the same there. If a native Mac build ships, it’ll be part of the v3.x updates your license already covers; we won’t promise a date we can’t keep.

Does it export emails?

No. Google’s API doesn’t return email addresses. You get name, category, rating, review count, address, phone, and website — the contact details businesses publish on their listings.

Do you see my leads, my searches, or my API key?

No. Everything runs on your machine: your key is stored locally, searches go straight from your computer to Google, and CSVs are written to your disk. There is no LeadMiner server in the middle collecting anything.

What’s the refund policy?

14 days. If it doesn’t work on your machine or isn’t what you expected, email us within 14 days of purchase for a full refund. The free 25-lead trial exists so you can verify it works before you’re anywhere near that window.
