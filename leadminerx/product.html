01 / What it does

A full city pull, not the first 60 results

01Single search

Type a keyword and a location (“Real estate agents | Troy, MI”) and get a CSV of matching businesses: name, category, rating, review count, address, phone, website, email, and search location — and watch them land in the Results tab as they are mined. A single Google query returns up to 60 results — use deep sweep to go past that.

02Bulk mode

Paste a list, one keyword | location per line, and mine a whole territory in one run.

03Five tabs, one window

Search, Results, Settings, License, and About — each in its own tab, with the Privacy Policy and Terms & Conditions links in the footer of every tab, always clickable. Settings save the moment you change them — no Apply button.

04Toggles that are real

Every export field and every function has a switch in Settings. Turn a field off and it is never even requested from Google, so you never pay for data you turned off. Deep sweep, duplicate skipping, email enrichment, the results limit, and CSV-or-JSON export all toggle the same way. Name is the one always-on field: it is a lead’s identity — dedup and the trial count key on it.

05Grid deep sweep

A single Google search stops at about 60 results. Deep sweep divides the map into a grid and searches each cell, so a full city pull returns hundreds of leads instead of the first 60 — coverage depends on Google’s listings for that area, so a sparse or rural pull can still come back under 60 total.

06Persistent dedup database

Every mined lead is remembered. Run the same search next month and duplicates are removed automatically, so re-runs only add new businesses to your CSV.

07Streaming export

Rows are written to the file as they arrive — CSV, or JSON if you pick it in Settings — not at the end. Stop a run at any point and everything mined so far is already saved.

08Your data stays yours

The app runs entirely on your machine. Your API key, your searches, and your CSVs never pass through us. Google processes your searches under your own Google Cloud account.

02 / Your API key

You’ll need a free Google API key

LeadMiner X talks to Google’s official Places API with a key in your own Google Cloud account. That is why there is no per-result fee to us: you pay Google’s published rate, and most small searches fit in Google’s free monthly allowance. The Settings tab walks you through setup, step by step, and tests your key before you mine — it takes about five minutes, and you don’t need to be a developer.

Get your key (about 5 minutes): 1) Open Google Cloud Console and create a project. 2) Enable billing on the project (required even for the free allotment). 3) APIs & Services → Library: enable Places API (New). 4) APIs & Services → Credentials: create an API key and restrict it to the Places API — Google’s own walkthrough is on Google’s API key page. 5) Paste the key into LeadMiner X and hit Test my key. Set a Google Cloud budget alert on the project while you’re there — it takes a few seconds and means Google emails you before spend ever surprises you.

  1. Create a free Google Cloud accountStep 1

    Use the account you have, or make one, and enable the Places API (New). Google asks for a billing card on the account; that’s Google’s requirement for API access, and it applies even if your usage stays inside the free allotment and your bill is $0.

  2. Follow the Settings-tab setup guideStep 2

    The Settings tab walks you through the key step by step and tests it — hit Test my key — before you mine anything.

  3. Your key stays on your machineStep 3

    It’s entered into the app, stored locally, and used only to call Google from your computer. We never see it, and we never see your leads. The key is yours, the billing account is yours, and you can set budgets and alerts in Google Cloud like any other API.

  4. What it costs youThe rate

    Because LeadMiner requests phone, website, rating, and review count, Google bills its requests at the Text Search Enterprise rate — 1,000 requests free per month, then $35 per 1,000 requests. Each request returns up to 20 leads, so your first ~1,000 requests each month cost $0 (up to ~20,000 leads, if every request returns 20 unique businesses), and past the free allotment the cost works out to about $1.75 per 1,000 leads when pages come back full — paid to Google, not us. LeadMiner adds nothing on top.

What the API does not provide: email addresses. Google doesn’t return them, and this tool doesn’t pretend to. So LeadMiner X reads each business’s own website and adds the address the business itself publishes — that’s the Email column above. Between the phone number, the website, and that published email, you have the contact points the business itself puts out for customers: use them for calls, walk-ins, and contact-form and email outreach.
