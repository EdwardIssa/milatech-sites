DRAE is in private development.

DRAE is Mila Tech’s ML and agent governance library — a research and development project that continues privately. It is not for sale, it is not available for licensing or subscription, and there is no public offering, pricing, or checkout for it.

Status

Where DRAE stands

Status as of November 9, 2026: DRAE is a working Python library that governs ML ensembles and AI agents by expert disagreement — it measures how much models disagree on each live decision, re-weights failing models, and halts execution fail-closed when the ensemble stops agreeing with itself. Earlier public pages about DRAE, including a past offer of the library for acquisition, have been withdrawn while the work continues privately and is rebuilt toward enterprise use. If DRAE returns to public availability, it will be announced on its own site. Questions about its status: edward@milatech.tech.
