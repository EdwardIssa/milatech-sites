02 / What it does

A full city pull, not the first 60 results

01Single search

Type a keyword and a location (“Real estate agents | Troy, MI”) and get a CSV of matching businesses: name, category, rating, review count, address, phone, website. A single Google query returns up to 60 results — use deep sweep to go past that.

02Bulk mode

Paste a list, one keyword | location per line, and mine a whole territory in one run.

03Grid deep sweep

A single Google search stops at about 60 results. Deep sweep divides the map into a grid and searches each cell, so a full city pull returns hundreds of leads instead of the first 60 — coverage depends on Google’s listings for that area, so a sparse or rural pull can still come back under 60 total.

04Persistent dedup database

Every mined lead is remembered. Run the same search next month and duplicates are removed automatically, so re-runs only add new businesses to your CSV.

05Streaming CSV

Rows are written to the file as they arrive, not at the end. Stop a run at any point and everything mined so far is already saved.

06Your data stays yours

The app runs entirely on your machine. Your API key, your searches, and your CSVs never pass through us. Google processes your searches under your own Google Cloud account.

04 / Your API key

Bring your own key — that’s the whole point

This is a bring-your-own-key tool. That’s deliberate — it’s why there’s no per-result fee. No invented stopwatch here: the in-app wizard walks you through setup step by step and tests your key before you mine — most people are running in a few minutes.

Get your key (about a minute once your account exists): 1) Open Google Cloud Console and create a project. 2) Enable billing on the project (required even for the free allotment). 3) APIs & Services → Library: enable Places API (New). 4) APIs & Services → Credentials: create an API key and restrict it to the Places API — Google’s own walkthrough is on Google’s API key page. 5) Paste the key into LeadMiner X and hit Test my key. Set a Google Cloud budget alert on the project while you’re there — it takes a few seconds and means Google emails you before spend ever surprises you.

  1. Create a free Google Cloud accountStep 1

    Use the account you have, or make one, and enable the Places API (New). Google asks for a billing card on the account; that’s Google’s requirement for API access, and it applies even if your usage stays inside the free allotment and your bill is $0.

  2. Follow the in-app setup wizardStep 2

    The wizard walks you through the key step by step and tests it before you mine anything.

  3. Your key stays on your machineStep 3

    It’s entered into the app, stored locally, and used only to call Google from your computer. We never see it, and we never see your leads. The key is yours, the billing account is yours, and you can set budgets and alerts in Google Cloud like any other API.

  4. What it costs youThe rate

    Because LeadMiner requests phone, website, rating, and review count, Google bills its requests at the Text Search Enterprise rate — 1,000 requests free per month, then $35 per 1,000 requests. Each request returns up to 20 leads, so your first ~1,000 requests each month cost $0 (up to ~20,000 leads, if every request returns 20 unique businesses), and past the free allotment the cost works out to about $1.75 per 1,000 leads when pages come back full — paid to Google, not us. LeadMiner adds nothing on top.

What the API does not provide: email addresses. Google doesn’t return them, and this tool doesn’t pretend to. So LeadMiner X reads each business’s own website and adds the address the business itself publishes — that’s the Email column above. Between the phone number, the website, and that published email, you have the contact points the business itself puts out for customers: use them for calls, walk-ins, and contact-form and email outreach.

06 / FAQ

Straight answers

Is this legal? Where does the data come from?

LeadMiner X uses Google’s official Places API — the same paid data channel Google sells to developers — with your own key on your own account. It does not scrape Google Maps or automate a browser against it (that’s what violates Google’s terms). You’re responsible for using the exported data in line with Google’s terms and the laws that apply to your outreach, same as any list you buy or build.

What do I need to run it?

A Windows PC and a free Google Cloud account for the API key. The setup wizard inside the app walks you through the key; you don’t need to be a developer.

How much will Google charge me, really?

First 1,000 API requests each month are free — up to ~20,000 leads, if every request returns 20 unique businesses. Past that, $35 per 1,000 requests works out to about $1.75 per 1,000 leads when pages come back full. A typical local campaign — a few thousand leads — costs $0 in API fees in a normal month. Google requires a billing card on the account even for free usage.

What happened to the $200 credit?

Google retired the old $200/month credit in March 2025 and replaced it with per-service free usage caps. For the tier this app uses (Text Search Enterprise), the cap is 1,000 free requests a month. Anyone still quoting you the $200 credit is working from an old price sheet.

How many computers can I install it on?

Your license covers your own machines for your own business use. It’s not for resale, sharing, or running a list-selling service for third parties.

Does it work on Mac?

Not natively — v3.1.0 is Windows-only. Mac users run it inside a Windows virtual machine (Parallels, VMware, UTM) and it works the same there. If a native Mac build ships, it’ll be part of the v3.x updates your license already covers; we won’t promise a date we can’t keep. Want to hear if a Mac build ships? Grab the free trial listing on Gumroad and you’re on the list.

Does it export emails?

Google’s API doesn’t return email addresses — but LeadMiner X reads each business’s own website during the run and adds the address the business itself publishes to an Email column. Roughly half of website-owning businesses publish one; the rest get an empty cell. You also always get name, category, rating, review count, address, phone, and website — the contact details businesses publish on their listings.

Do you see my leads, my searches, or my API key?

No. Everything runs on your machine: your key is stored locally, searches go straight from your computer to Google, and CSVs are written to your disk. There is no LeadMiner server in the middle collecting anything. Google processes your searches under your own Google Cloud account.

What’s the refund policy?

14 days. If it doesn’t work on your machine or isn’t what you expected, email us within 14 days of purchase for a full refund. The free 25-lead trial exists so you can verify it works before you’re anywhere near that window.
