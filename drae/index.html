DRAE — governance for models that drift.

DRAE (Drift-Regulated Adaptive Ensemble) is a working Python library that watches expert disagreement — ω, omega — as a live health signal for ML ensembles and AI agents. When a model goes stale or an agent’s proposals drift, DRAE re-weights the failing expert, degrades operation gracefully, and halts execution fail-closed when instability spikes. 01 / The system

What DRAE is

Ensembles and multi-agent systems fail quietly: one model goes stale, one agent drifts, and the averaged output stays plausible while it gets worse. DRAE treats disagreement itself as the alarm — and acts on it deterministically.

01Adaptive Controller

Re-weights experts in proportion to their local disagreement, with a Dirichlet entropy floor so the ensemble can never collapse onto a single expert.

02Regime Manager

A hysteresis switch between passive monitoring and active control tightens the system under sustained drift — without mode-flapping.

03Cold-Start Guard

Suppresses safety decisions until enough baseline statistics exist, with a smooth sigmoid activation once the system is warmed up.

04Policy Interlock

Separates level from rate of change: elevated ω degrades operation; a sudden Δω spike halts execution, fail-closed.

05Agent Governor

The same kernel arbitrates AI agents’ proposed actions by intent-vector disagreement, under the same interlock and recovery rules.

06Telemetry & Recovery

Every decision frame is recorded through a queue/exporter pipeline with a Redis stream transport; cooldown recovery escalates when a fault survives it.

03 / Evidence

Measured, not asserted

A reproducible benchmark ships with the code (seed-locked): the same three base learners, the same data, a static equal-weight ensemble versus DRAE’s adaptive weighting.

Benchmark · Reproducible

When one expert corrupts, DRAE holds the line

In the expert-degradation scenario — one of three models progressively corrupts mid-stream, the classic stale-model failure — the static ensemble keeps averaging the broken model at full weight. DRAE detects the disagreement, down-weights it, and its interlock fires on 20 of 30 evaluation batches.

−85.6% MSE vs static ensemble −91.9% MSE in the second half Interlock active on 20 of 30 batches

A second scenario is reported just as honestly: when every expert fails identically at once (abrupt sign-flip drift), disagreement carries no signal and DRAE shows no gain — a documented limit, printed in the results file next to the win.
